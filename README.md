# 📊 GeoSpatial Analytics Dashboard

An advanced, serverless client-side Web-GIS analytics dashboard built with **Leaflet.js**, **Turf.js**, **Chart.js**, and **Bootstrap 5**.

🔗 **Live Demo:** <a href="https://halilsertkaya.github.io/spatial-analysis-dashboard/" target="_blank">View Live on GitHub Pages</a>

---

## 🚀 Key Features
* **Client-Side Spatial Analysis (Turf.js):** Perform on-the-fly buffer zone calculations and spatial containment queries directly in the browser without server overhead.
* **Interactive Proximity Tool:** Click anywhere on the map and adjust the radius slider (10 km - 200 km) to query nearby geographical risk zones instantly.
* **Statistical Visualization (Chart.js):** Real-time doughnut charts displaying the breakdown of risk levels across the dataset.
* **Zero Backend Architecture:** Runs entirely on static HTML/JS, making it lightning-fast and fully compatible with free hosting providers like GitHub Pages.

---

## 🛠️ How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any modern web browser. No server setup required!
